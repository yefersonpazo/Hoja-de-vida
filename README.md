# Hoja de vida

Portfolio personal creado con React y Vite.

## Requisitos

- Node.js 18+

## Desarrollo

Instala las dependencias y arranca el servidor local:

```sh
npm install
npm run dev
```

Vite mostrará la URL local en la terminal.

## Compilar para producción

```sh
npm run build
npm run preview
```

La compilación queda en `dist/`. Las imágenes y certificados originales se
mantienen en las carpetas `IMG/` y `PDF/`.
